# 02: Design and select the marketing direction

**What to build:** Create three static Relay marketing-site directions for review. Use the same approved mark, lockup, palette, typography, product facts, brand line, calls to action, and viewport assumptions in all three. Make the page structures meaningfully different so the choice is about layout and emphasis. Publish the review artifacts, collect the product owner's choice, and record the selected direction before implementation starts.

**Blocked by:** Ticket 01.

**Status:** complete

- [x] Three complete static homepage directions exist and differ in page structure rather than colour alone.
- [x] Every direction uses the approved production assets, true black, white, zinc neutrals, Geist Sans, and Geist Mono where fixed-width text helps.
- [x] Every direction explains Relay as a video workflow workspace for freelance video editors and small editing teams.
- [x] Every direction includes the line "From first cut to final handoff." and uses concise product-specific copy.
- [x] Every direction shows desktop and mobile layouts with usable navigation and a clear primary call to action.
- [x] The designs avoid gradients, glow, glass effects, decorative card systems, fixed accent colours, and continuous animation.
