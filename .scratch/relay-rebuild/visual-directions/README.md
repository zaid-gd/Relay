# Relay visual directions

The product owner reviewed three light-first directions for Relay's Dashboard and Project page. Each direction includes separate desktop and tablet images.

## 1. Command Canvas

Command Canvas puts search and quick actions first, then uses broad flat sections for work queues. It keeps the navigation quiet so the current task remains dominant.

- [Desktop Dashboard](command-canvas/dashboard.png)
- [Tablet Dashboard](command-canvas/dashboard-tablet.png)
- [Desktop Project](command-canvas/project.png)
- [Tablet Project](command-canvas/project-tablet.png)

## 2. Production Desk

Production Desk uses a compact operating view with dense tables, a visible project inspector, and short attention queues. It suits editors who scan many records at once.

- [Desktop Dashboard](production-desk/dashboard.png)
- [Tablet Dashboard](production-desk/dashboard-tablet.png)
- [Desktop Project](production-desk/project.png)
- [Tablet Project](production-desk/project-tablet.png)

## 3. Sidebar Canvas — selected

Sidebar Canvas uses a unified dark application shell around a warm light canvas. Every main content block has its own flat bordered card, while table rows remain unboxed. The desktop images show the expanded sidebar; the tablet images show its collapsed icon rail.

- [Desktop Dashboard](sidebar-canvas/dashboard.png)
- [Tablet Dashboard](sidebar-canvas/dashboard-tablet.png)
- [Desktop Project](sidebar-canvas/project.png)
- [Tablet Project](sidebar-canvas/project-tablet.png)

All three directions use 14–16 px body copy, thin borders, strong type, indigo actions, text or icons alongside semantic colour, and restrained state motion. They use named demo fixtures and abstract media only. Dark mode follows the checked token rules in the chosen design record. The product owner asked not to render dark-mode screens during this ticket.
