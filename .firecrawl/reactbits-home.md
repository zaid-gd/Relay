## The code is yours

React Bits isn't a package you depend on. Each component lands in your repo as source you own.

- ### No wrapper library

Components use ogl, GSAP and friends directly, no react-bits dependency.

- ### Edit anything

It is your source now. Change the shader, the props, the styling, all of it.

- ### No lock-in

If this site vanished tomorrow, everything you already added keeps working.
